# 状況要約（Nanokuro Official）

更新: 2026-11-27

静的サイト。公開は GitHub Pages（`main`）。デプロイはユーザーが頼んだときだけ。手順は skill `nanokuro-official-deploy`。2nd Collections の Release ビルドは使わない。手元の見た目と公開中のサイトは一致しないことがある。

プレビューはプロジェクト直下で `python -m http.server 8765 --bind 127.0.0.1`。キャッシュは `site.css?v=20261127o`、`site.js?v=20261127g`。

## 譜面一覧のいま

- メタ行は `Composer · Charter: …` だけ。難易度が分かれ、かつチャーターも違う曲だけ個別（Crystal は `IN: … / AT: …`）。キーモード・区分・版の注記は出さない。
- 全曲に左上コーナー。IN は赤 `#ff3b3b`、AT は灰 `#8a929c`、SP は白、IN と AT の両方がある曲は上辺が赤で縦辺が灰、4K の KIZUNA はシアン。形は `assets/ornaments/corner-mask.png`。カード、プレート、DL画面の左上も同じ形で、色はシアン。古い `corner.png` は使わない。
- 行にカーソルが乗っても、左端の短い光は出さない。コーナー付きカードも、左端の線は出さない。
- マークは難易度の文字だけ。OPEN などの状態表示、状態の絞り込み、ソートの「状態」は無い。マーク左の色点も無い。定数 17 以上の紫グローと 18 以上の赤グローは残す。
- マークの文字は 10.125px（いったん 1.5 倍にしたあと 25% 縮小）。
- PC: 曲名とコンポーザー・Charter が左、マークが右。
- 幅 860px 以下: マークは右詰め。コンポーザー・Charter はその下。曲名が長くてマークが入りきらなければ、マークも下の段。
- ソート・配布・区分の選択肢は、開いた一覧の背景が暗い（`color-scheme: dark`）。
- 免責文はフッターの先頭。保管庫ページでは、下の「？」・BGM・複数選択に被らないようフッター下に空きがある。

## 変えないこと

- D-Birth は YouTube のみ。zip では配らない。Clock Paradox は Access Denied のまま。
- TRPG の HTML は残す。サイト内からの導線は外してある。
- ホームの 2nd バナーは遷移せず、Access Denied を出す。左からスライドインし、2.5 秒後に左へスライドアウトする。入りと出のアニメーション中は、もう一度押しても新しいアニメーションは始まらない。
- Cloudflare Workers の前段は作らない。
- 行全体の背景画像は未実装。PixAI のプロンプトだけ渡した。
- `charts.json` の短い `"note"` を一括置換しない。チャーター表記は `Name , Name`。Unraveling Stasis は `Threads of Noχious (Nanokuro and 山田悠牙)`。
- コミットとデプロイは頼まれたときだけ。失敗した Pages のジョブは rerun しない。
